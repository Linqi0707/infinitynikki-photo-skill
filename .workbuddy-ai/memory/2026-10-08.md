## Web UI v2: Masonry Layout + Edit Mode + Pagination
- Photo wall: changed from CSS Grid to column-based masonry (`column-width: 240px`, `break-inside: avoid`)
- Images use `height: auto` (natural proportions), no forced aspect-ratio — landscape and portrait mix seamlessly
- Mobile: `column-width: 150px` for fewer columns
- Edit mode: "编辑" button in detail modal → dropdowns for 7 semantic fields (photo_type, framing, view, scene, game_time, color_tone, background) + text inputs for outfit_code/description and camera_code/description
- orientation is read-only in edit mode (derived from image dimensions)
- PUT /api/photo/<photo_id>: UPSERT photo_semantics, update-or-insert outfit/camera_params, validation, transaction with rollback, returns full updated detail
- Save: calls PUT API, refreshes detail in-place (no page reload), also silently refreshes photo wall
- Pagination: page number window (5 around current), first/last/prev/next buttons, ellipsis, jump-to-page input
